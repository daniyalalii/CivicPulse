## 4. CORS Configuration

```python
# backend/app/config.py
cors_origins: list[str] = ["*"]   # default — accepts any origin

# backend/app/main.py
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins,  # ["*"]
    allow_credentials=True,               # ⚠️ SEE NOTE BELOW
    allow_methods=["*"],
    allow_headers=["*"],
)
```

> **⚠️ CORS BUG — `allow_credentials=True` + `allow_origins=["*"]` is INVALID.**
>
> The CORS spec forbids `Access-Control-Allow-Credentials: true` when `Access-Control-Allow-Origin: *`.
> Browsers will block every credentialed request (i.e., any request that sends cookies or `Authorization` headers).
>
> **What to change in the backend (`backend/app/config.py`):**
> ```python
> # Option A – development (no credentials needed since there's no auth)
> cors_origins: list[str] = ["http://localhost:5173"]
>
> # Option B – if credentials ever become needed, list origins explicitly
> cors_origins: list[str] = ["http://localhost:5173", "https://your-prod-domain.com"]
> # AND keep allow_credentials=True in main.py
> ```
>
> Since there's currently no auth (no cookies, no Authorization header), the frontend won't send credentials, so browsers won't reject the wildcard. But it's still a latent bug. The safe fix is **Option A**.
